# BrickBuilder application icon

The transparent PNGs use the user-supplied BrickBuilder logo. The source artwork
already contains alpha transparency, which is preserved in every generated size.
This is not a trademark clearance or an assertion of affiliation.

- `brickbuilder-512.png`: 512 × 512 RGBA master used by the PWA and Android icon variants.
- `brickbuilder-192.png`: 192 × 192 PWA and browser icon.

Android launcher foregrounds are generated from the same master in each density
folder. Adaptive launcher backgrounds are transparent, and the foreground keeps
padding for launcher masks. Some launchers may still apply their own icon styling.
